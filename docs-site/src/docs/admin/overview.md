# 管理功能总览

管理后台用于维护用户、上游账号池、模型分组、计费价格、支付渠道和运维状态。不同部署版本和权限配置下，菜单可能略有差异。

## 常见模块

| 模块 | 用途 |
|------|------|
| 仪表盘 | 查看整体用量、收入、错误、用户和模型趋势 |
| 用户管理 | 创建、禁用、调整余额、查看用户用量和 API Key |
| API Key 管理 | 调整用户令牌分组、排查调用问题 |
| 分组管理 | 配置平台、模型、倍率、RPM 覆盖和用户可见范围 |
| 账号池 | 管理 Claude、OpenAI、Gemini、Antigravity 等上游账号 |
| 渠道监控 | 对外展示或内部检查渠道、模型和分组状态 |
| 支付管理 | 配置支付实例、查看订单和审计日志 |
| 公告 | 发布站点公告或维护通知 |
| 风控 | 内容审核、封禁、风险日志和策略配置 |
| Ops | 查看并发、实时流量、错误、系统日志和告警 |
| 备份 | 管理数据备份、恢复和清理策略 |

## 配置顺序建议

首次部署后建议按以下顺序配置：

1. 完成管理员账号和站点基础设置；
2. 配置上游账号池；
3. 创建模型分组和倍率；
4. 配置测试用户和 API 令牌；
5. 进行 OpenAI / Claude / Gemini 调用测试；
6. 配置支付、公告、邮件和风控；
7. 配置备份、监控和日志保留策略。

## 高风险操作

以下操作会直接影响线上用户，请谨慎执行：

- 批量修改账号分组或模型映射；
- 删除分组或账号；
- 修改全局计费倍率；
- 修改支付回调配置；
- 清理日志或备份；
- 批量禁用用户或 API Key。

建议在操作前记录当前配置，必要时先在测试环境验证。
