# 支付系统配置

FreeCode / Sub2API 内置支付系统，可用于余额充值、订阅购买和订单管理。支持的渠道取决于部署配置和版本。

## 支持渠道

常见支付渠道包括：

- EasyPay；
- Alipay；
- WeChat Pay；
- Stripe；
- Airwallex。

详细字段和接口说明请以仓库内 `docs/PAYMENT_CN.md` 与 `docs/ADMIN_PAYMENT_INTEGRATION_API.md` 为准。

## 配置前准备

- 支付商户号或平台账号；
- API Key、私钥、公钥或 webhook secret；
- 可公网访问的回调域名；
- HTTPS 证书；
- 明确的充值套餐或订阅套餐；
- 一笔小额测试支付的预算。

## 回调地址

支付渠道通常需要配置异步通知或 webhook 地址。请确保：

- 域名可以被支付平台公网访问；
- 反向代理不会拦截回调路径；
- 后端能正确识别签名、订单号和金额；
- 测试环境和生产环境的密钥不要混用。

## 订单状态排查

| 现象 | 可能原因 |
|------|----------|
| 用户已支付但未到账 | 回调未到达、签名验证失败、订单金额不匹配 |
| 订单一直待支付 | 用户未完成付款或支付渠道未回调 |
| 支付页面打不开 | 支付实例未启用、代理拦截、渠道配置错误 |
| Stripe/Airwallex 弹窗异常 | 前端公钥、client secret 或回调域名配置错误 |

## 安全要求

- 支付密钥不得写入公开仓库；
- 后台页面和日志中应避免展示完整密钥；
- 修改支付配置后先做小额测试；
- 定期核对支付平台流水和系统订单；
- 出现异常订单时保留审计日志，避免直接删除证据。
