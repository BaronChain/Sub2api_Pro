# 账号池与分组

账号池和分组是 FreeCode 调度与计费的核心。账号池决定“请求从哪里出去”，分组决定“用户能用什么模型、按什么倍率计费”。

## 账号池

账号池中可以维护不同平台的上游账号，例如：

- Claude / Anthropic；
- OpenAI / Codex；
- Gemini；
- Antigravity；
- Bedrock / Vertex 或其他兼容渠道。

每个账号通常包含平台、类型、凭据、代理、模型映射、可调度状态、优先级和错误状态等信息。

## 分组

分组用于面向用户开放能力：

- 绑定平台和可用模型；
- 设置倍率和价格；
- 控制用户或订阅可见范围；
- 设置 RPM 或模型级别覆盖；
- 支持折扣分组、官方分组或特定用途分组。

## 模型映射

模型映射错误是最常见的线上问题之一。修改映射前请确认：

1. 上游账号实际支持哪些模型；
2. 用户侧暴露的模型名是否和客户端一致；
3. 映射后是否会影响已有用户配置；
4. 是否需要同步上游模型列表；
5. 是否需要在模型广场或公告中说明变化。

## 调度排查

如果用户反馈“无可用账号”或“Service temporarily unavailable”，管理员可以检查：

- 账号是否启用且可调度；
- 账号是否达到并发、RPM 或上游额度限制；
- 账号是否被临时标记为不可调度；
- 分组是否关联了可用账号；
- 用户是否拥有该分组权限；
- 模型映射是否为空或错误。
