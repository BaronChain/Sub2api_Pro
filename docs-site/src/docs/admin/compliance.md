# 合规与风控

部署和运营 FreeCode / Sub2API 时，管理员需要对服务使用方式、用户行为、内容安全和数据保护承担责任。

## 部署者责任

- 遵守所在国家或地区法律法规；
- 遵守上游服务条款和使用政策；
- 明确告知用户服务边界、计费方式和禁止用途；
- 对违法、滥用、攻击、垃圾信息等行为建立处理流程；
- 对用户数据、日志和凭据采取必要保护措施。

## 风控建议

- 启用内容审核或风险控制策略；
- 对异常高频请求、撞库、滥用注册进行限流；
- 对高风险用户或 API Key 及时禁用；
- 保留必要审计日志，但避免长期保存不必要的敏感内容；
- 对外发布清晰的服务条款、使用政策和隐私说明。

## 凭据与隐私

管理员可能接触上游账号、OAuth token、支付密钥和用户 API Key。请遵守：

- 不在聊天、截图或工单中发送完整密钥；
- 不把 `.env`、真实 `config.yaml`、私钥、OAuth secret 提交到仓库；
- 导出数据前确认是否需要脱敏；
- 只给必要人员授予管理员权限。
