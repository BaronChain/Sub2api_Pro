# 模型广场（令牌分组查看）

## 如何查看最新分组

在控制台面板，点击右上角“模型广场”，进入分组与模型的查看。

进入模型广场后，左侧就是 [创建 API 令牌](../register/4-token.md) 步骤提到的令牌分组，右侧就是该分组下所存在的模型。

## 倍率说明

左侧分组名后显示的类似 `x0.5` 就是该分组的计费倍率。选择不同令牌分组可以享受不同的计费倍率：

- **倍率 < 1 享折扣**：0.8 倍 = 8 折，0.5 倍 = 5 折。
- **倍率 > 1 需加价**：1.5 倍 = 额外支付 50% 费用。
- **不选择**则使用你的默认计费倍率（1x）。

::: tip 为什么要教你这一步？
授人以鱼不如授人以渔。很多人只知道去看分组名，却不知道这个分组下有哪些模型，稀里糊涂配置以后，使用就会提示“模型不存在”。

为了杜绝这种情况，我们直接教你如何查看每个分组的详细信息：在模型广场选中分组，右侧即可看到该分组支持的全部模型与价格。
:::
