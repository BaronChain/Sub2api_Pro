# 支持的国家和地区

::: important 重要提示
本页为概要说明。完整、最新的支持区域列表请以 FreeCode 官网政策页面为准：<https://freecode.codes/supported-regions>
:::

## 概述

FreeCode 仅在适用法律允许的国家和地区提供服务。你不得将服务出口或提供访问权限给被相关法律禁止的人员、实体或国家，也不得用于被禁止的用途。

## 使用要求

- 你须确认所在国家或地区在 FreeCode 当前支持的范围内。
- 你不得通过技术手段规避地区限制访问服务。
- 受相关出口管制或制裁覆盖的人员、实体或国家不得使用本服务。
