# 服务条款（TOS）

::: important 重要提示
本页为概要说明。完整、具有法律效力的版本请以 FreeCode 官网政策页面为准：<https://freecode.codes/terms>
:::

## 概述

这些商业服务条款（“条款”）是 FreeCode 与你或你所代表的组织（“客户”）之间的协议，规定客户对 FreeCode API 密钥及相关产品、工具、文档和服务（“服务”）的使用。条款自客户首次电子方式同意或首次访问服务（以较早者为准）起生效。

## 关键要点

- **客户内容**：客户保留输入的所有权利并拥有输出；FreeCode 不使用来自服务的客户内容训练模型。
- **使用限制**：不得逆向工程、抓取、批量提取、绕过速率限制，或用服务构建/训练竞争模型。
- **账户安全**：客户对其账户、API 密钥下的所有活动负责，凭据泄露应立即通知 FreeCode。
- **退款政策**：基于客户自身意愿变更的退款可能被拒绝；因违规产生的费用不予退还；具体以官网退款政策为准。
- **责任限制**：在法律允许范围内，不承担间接、偶然、特殊损害；责任上限为前 12 个月支付的费用。
