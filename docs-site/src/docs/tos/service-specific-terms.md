## 概述

服务特定条款是 [服务条款](./TOS.md) 的补充，针对特定上游平台、模型或功能（如 OpenAI、Claude、Gemini 及其兼容接口）的使用作出额外约定，并通过引用纳入服务条款。

## 主要约定

- **第三方上游约束**：当你使用通过 FreeCode 转发的第三方模型、云平台、兼容接口、支付渠道等功能时，须同时遵守该第三方的服务条款、使用政策、地区限制、模型定价与文档。
- **可用性变更**：第三方产品的变更、暂停、终止、模型下线、价格调整或不可用，可能影响你对服务的使用，FreeCode 对此类第三方功能不承担责任。
- **输出局限性**：你有责任在使用或共享输出前评估其适用性，必要时进行人工审查；不应在未独立核实的情况下依赖输出中的事实断言。
- **嵌入与披露**：若将服务嵌入你自己的产品、代理、机器人、插件或平台，你须向终端用户提供适当披露，并对其使用负责。
