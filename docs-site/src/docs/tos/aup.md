# 使用政策（AUP）

::: important 重要提示
本页为概要说明。完整、具有法律效力的版本请以 FreeCode 官网政策页面为准：<https://freecode.codes/usage-policy>
:::

## 概述

使用政策（也称“可接受使用政策”/“AUP”）适用于任何向 FreeCode 产品和/或服务提交输入的用户（含通过授权经销商或直通访问）。本政策旨在帮助用户保持安全并促进负责任地使用服务。

随着技术和相关风险的发展，FreeCode 会更新本政策。为执行本政策，FreeCode 可使用检测、审查和监控机制；如用户违反本政策，FreeCode 可限制、暂停或终止访问，也可阻止、过滤或修改违反本政策的输入或输出。

## 通用使用标准

以下标准适用于所有用户和所有用例，不得使用本服务从事或协助：

- 违反适用法律或从事非法活动
- 危害关键基础设施
- 危害计算机或网络系统
- 开发或设计武器
- 煽动暴力或仇恨行为
- 侵犯隐私或身份权利
- 危害儿童安全
- 创建心理或情感上有害的内容
- 创建或传播错误信息
- 破坏民主进程或参与有针对性的竞选活动
- 用于刑事司法、审查、监视或被禁止的执法目的
- 从事欺诈、滥用或掠夺性做法
- 滥用平台（绕过保护措施、越狱、提示注入、未授权抓取/复制/微调、违反速率限制等）
- 生成性露骨内容

## 高风险用例

涉及法律、医疗保健、保险、金融、就业和住房、学术测试、媒体新闻等领域时，属于高风险用例，需实施额外安全措施：

- **人在回路中**：合格专业人员须在传播或最终确定前审查内容或决策。
- **披露**：若模型输出直接呈现给个人或消费者，必须披露正在使用 AI 辅助生成。

## 其他用例指南

- 所有面向消费者的聊天机器人/交互式 AI 代理，必须在每次会话开始时向用户披露其正在与 AI 交互。
- 面向未成年人的产品须遵守附加指南。
- 代理用例仍须遵守本使用政策。
