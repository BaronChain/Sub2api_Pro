# Nano Banana2 Pro 绘图教程

## 使用 Cherry Studio 绘图

1. 参照 [创建 API 令牌](../register/4-token.md)，创建令牌分组为 **gemini** 的令牌。创建好后，点击复制按钮，将令牌复制到剪切板。
2. 访问 Cherry Studio 官网下载并安装。
3. 打开 Cherry Studio，点击右上角设置按钮。
4. 选择左侧 **模型服务**，点击最下面的 **添加** 按钮。
5. 在添加提供商窗口写入提供商名称与提供商类型。
6. 在左侧列表中找到刚添加的分组，**API 密钥** 填入第 1 步复制的 gemini 分组 API Key，**API 地址** 填写 `https://freecode.codes`。
7. 点击下方 **管理** 按钮，在弹出的模型列表中选择绘图模型并添加。
8. 点击左上角 **首页** 回到主页，点击当前助手右侧设置按钮。
9. 在 **模型设置** 一栏找到 **流式输出**，**请务必关闭**，然后关闭窗口。
10. 在上方模型设置处，选择刚才创建分组的绘图模型。

尽情发挥你的想象吧~

::: tip 提示
绘图请求通常比普通对话耗时更久，请关闭流式输出，并尽量直连 `freecode.codes`，避免经过会限制长连接的代理导致请求中断。
:::
