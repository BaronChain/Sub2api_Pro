# 可用渠道与模型状态

“可用渠道”用于查看当前用户可访问的平台、分组、模型和渠道状态。它可以帮助你判断问题到底出在客户端配置、令牌分组，还是上游渠道。

## 可用渠道能看什么

不同站点展示字段可能不同，常见信息包括：

- 平台：例如 Claude / OpenAI / Gemini / Antigravity 等；
- 分组：当前用户可使用哪些令牌分组；
- 支持模型：该平台或渠道支持的模型列表；
- 渠道状态：是否可用、是否维护中、是否限流；
- 额外说明：计费来源、模型限制或临时公告。

## 和模型广场的区别

- **模型广场**：更适合查看分组、模型和倍率，帮助你创建正确的 API 令牌。
- **可用渠道**：更适合排查调用失败，确认当前用户实际能访问哪些平台和模型。

建议创建令牌前先看模型广场；调用失败时再看可用渠道。

## 常见场景

### 模型广场有模型，但客户端提示模型不存在

可能原因：

1. API 令牌选错分组；
2. 客户端配置的模型名拼写错误；
3. 使用了 OpenAI 兼容入口调用 Claude/Gemini 专用模型；
4. 当前账号没有该分组权限；
5. 模型刚调整，客户端缓存未刷新。

### 令牌分组正确，但仍然无法调用

请检查：

- 可用渠道中对应平台是否可用；
- 账户余额是否充足；
- 令牌是否启用；
- 是否设置了 IP 白名单或模型限制；
- 是否达到并发或周期额度限制。

### 渠道维护或上游异常

如果可用渠道显示维护或异常，通常不是本地配置问题。可以稍后重试，或切换到同平台其他可用模型/分组。
