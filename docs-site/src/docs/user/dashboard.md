# 控制台与仪表盘

登录 FreeCode 后，控制台会展示账户当前状态和近期使用情况。仪表盘适合用来快速判断“账号是否还有余额”“最近是否有调用”“哪个模型消耗较多”。

## 常见信息

仪表盘通常会展示：

- **账户余额**：当前账户可用于 API 调用或订阅购买的余额。
- **今日 / 近期用量**：按时间统计的调用消耗。
- **模型用量分布**：不同模型产生的用量占比。
- **近期调用记录**：最近 API 请求的模型、时间、消耗和状态。

::: tip
不同站点配置可能会隐藏部分卡片或菜单。请以你当前控制台实际显示为准。
:::

## 推荐检查顺序

如果你发现 CLI 或客户端无法调用，建议先按下面顺序检查：

1. 查看账户余额是否充足。
2. 查看 [API 令牌](./api-key.md) 是否启用、是否选对分组。
3. 查看 [可用渠道](./channels.md) 中对应平台和模型是否可用。
4. 查看 [用量与计费](./usage-billing.md) 中是否有失败记录或额度耗尽记录。
5. 再到对应工具的 FAQ 中排查客户端配置问题。

## 余额与令牌额度的关系

FreeCode 中可能同时存在“账户余额”和“单个 API 令牌额度”。一般情况下：

- 账户余额是总上限；
- 令牌额度是某个 API Key 的局部限制；
- 即使某个令牌设置为无限额度，最终也仍然受账户余额、订阅、分组权限、风控策略和平台限额影响。
