# 兑换码、邀请返佣与订单

FreeCode 控制台可能提供兑换码、邀请返佣、订阅购买和订单记录等功能。不同站点会根据运营策略启用或隐藏部分入口。

## 兑换码

兑换码通常用于发放余额、订阅权益或活动奖励。

使用步骤：

1. 登录控制台。
2. 进入“兑换码”页面。
3. 粘贴兑换码并提交。
4. 查看兑换结果和历史记录。

::: tip
兑换码一般有有效期、使用次数、适用用户或适用权益限制。如果提示不可用，请确认兑换码是否过期、是否已经使用过、是否适用于当前账号。
:::

## 邀请返佣

邀请返佣功能用于通过邀请链接邀请新用户，并在对方满足条件后获得奖励。常见信息包括：

- 邀请链接或邀请码；
- 已邀请用户列表；
- 待结算和可转入余额；
- 返佣规则说明。

具体返佣比例、结算周期和提现/转余额规则，请以控制台显示和站点公告为准。

## 订阅购买

如果站点开启订阅功能，用户可以在订阅或购买页面选择套餐。购买前建议确认：

- 套餐包含的分组或模型；
- 有效期；
- 并发或用量限制；
- 是否自动续费；
- 是否可退款或变更。

## 订单记录

订单页面用于查看充值、订阅购买和支付状态。常见状态包括：

| 状态 | 含义 |
|------|------|
| 待支付 | 订单已创建，但尚未完成付款 |
| 支付中 | 已跳转或等待支付渠道确认 |
| 已完成 | 支付成功，权益通常会自动到账 |
| 已取消 | 用户取消或订单超时关闭 |
| 失败 | 支付渠道返回失败或系统处理失败 |

## 支付没有到账怎么办

1. 不要重复快速创建多个订单，先等待支付渠道回调。
2. 到订单页面刷新状态。
3. 确认支付金额、支付渠道和订单号。
4. 如果长时间未到账，联系站点支持并提供订单号、支付时间和支付截图。
