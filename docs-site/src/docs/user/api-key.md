# API 令牌高级设置

API 令牌也常被称为 API Key、密钥或令牌。它是客户端调用 FreeCode 的访问凭据，请像密码一样妥善保存，不要在群聊、截图、公开仓库或日志中泄露。

第一次创建令牌请先阅读 [创建 API 令牌](../register/4-token.md)。本页补充说明创建和编辑令牌时常见的高级选项。

## 基础字段

| 字段 | 说明 | 建议 |
|------|------|------|
| 名称 | 便于自己识别用途，例如 `claude-code-laptop` | 按工具或设备命名 |
| 分组 | 决定这个令牌能调用哪些模型和平台 | Claude Code 选 CC，Codex 选 Codex，Gemini 选 Gemini |
| 额度 | 限制该令牌最多可消耗的金额 | 不熟悉时先设置较小额度 |
| 无限额度 | 不给单个令牌设置局部额度上限 | 仍受账户余额和平台策略限制 |
| 状态 | 启用或禁用该令牌 | 不再使用时及时禁用或删除 |

## 分组一定要选对

令牌分组决定可用模型范围。分组选错时，常见表现包括：

- 客户端提示模型不存在；
- 请求返回 403 或无权限；
- 可用渠道中能看到模型，但当前令牌无法调用；
- Claude Code、Codex、Gemini CLI 中某一个工具可用，另一个不可用。

不确定时，请到 [模型广场](../token/1-intro.md) 查看每个分组下的模型。

## 访问限制

部分站点会允许为 API 令牌设置额外限制：

- **IP 白名单**：只允许指定 IP 使用该令牌。适合服务器固定出口；不适合家庭宽带、移动网络或频繁切换网络的设备。
- **模型限制**：只允许调用指定模型。适合团队分发令牌时控制成本。
- **过期时间**：到期后令牌自动失效。适合临时测试或短期共享。

::: warning
如果你不确定自己的公网 IP 是否固定，不建议开启 IP 白名单。否则换网络后很容易出现“明明 Key 正确但无法调用”的情况。
:::

## 速率与周期额度

令牌可能支持 5 小时、1 天、7 天等周期限制。达到限制后，即使账户仍有余额，该令牌也可能暂时不可用。

常见处理方式：

1. 等待当前周期自动恢复；
2. 在令牌编辑页查看已用量和上限；
3. 如果你确认需要继续使用，可以调整限制或重置周期用量；
4. 如果是团队令牌，请先确认是否有人异常消耗。

## 删除、禁用与重置

- **禁用**：临时停止该令牌，后续可以重新启用。
- **删除**：永久移除该令牌，客户端中保存的 Key 会立刻失效。
- **重置已用额度**：只影响该令牌的局部额度统计，不等于恢复账户余额。
- **重置限速用量**：只影响周期限制统计，不代表上游平台限制一定恢复。

## 推荐实践

- 每个工具单独创建一个令牌，便于排查和控制额度。
- 不要把同一个令牌同时发给多人使用。
- 长期不用的令牌及时禁用或删除。
- 公开截图前打码完整 API Key。
- 遇到调用失败时，先复制一个新令牌测试，排除旧令牌配置问题。
